# Decisions

| Date       | Decision                                                                                                      | Reason                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 2026-09-30 | `@mrdash/shared` is compiled to `dist/` by `tsc`; root `typecheck`/`test`/`dev` build it first.               | Keeps Node ESM runtime and Vite both resolving one artifact without a bundler.                      |
| 2026-09-30 | Pinned TypeScript 5.9, ESLint 9, Prisma 6, jsdom 26.                                                          | Newest majors (TS 7, ESLint 10, jsdom 30) are unsupported by typescript-eslint / Node 20.           |
| 2026-09-30 | Prisma schema has only generator+datasource in Phase 1; health check uses `SELECT 1`.                         | Health must report DB status now; models arrive in Phase 2. `prisma migrate deploy` is a no-op.     |
| 2026-09-30 | Added `fastify-plugin`, `pino-pretty`, `tsx`, `concurrently`, `@tailwindcss/vite`.                            | Needed for the error-handler plugin, dev logging, dev runner, parallel dev, and Tailwind v4 build.  |
| 2026-09-30 | Postgres init script (`docker/postgres-init.sql`) creates `mrdash_test`.                                      | Compose only creates one DB via env; the init script creates the second.                            |
| 2026-09-30 | `/api/health` returns 503 with `db: "down"` when the DB is unreachable.                                       | Lets load balancers/CI detect an unhealthy instance.                                                |
| 2026-09-30 | `pnpm e2e`, `db:seed`, `db:seed:large` are placeholder no-ops.                                                | Listed in CLAUDE.md commands; real implementations belong to later phases.                          |
| 2026-10-01 | Trigram indexes declared in `schema.prisma` via `postgresqlExtensions` preview + `gin_trgm_ops`.              | Keeps the schema and migrations in sync so `migrate dev` reports no drift.                          |
| 2026-10-01 | Added `ReviewerState` enum and `webhook_events(receivedAt)`, `sync_runs(repositoryId, startedAt)` indexes.    | Spec lists reviewer states but no enum name; indexes support retention job and latest-sync lookups. |
| 2026-10-01 | Seeds truncate all tables first and use fixed PRNG seeds; seed task status uses a small local rollup.         | Re-runnable and reproducible; canonical status logic arrives in `packages/shared` in Phase 3.       |
| 2026-10-01 | Server tests run serially (`fileParallelism: false`) with a global setup that runs `migrate deploy`.          | All DB tests share one Postgres database that is truncated between files.                           |
| 2026-10-01 | Server `test` script runs `prisma generate` first.                                                            | Tests import the generated client; fresh checkouts would otherwise fail.                            |
| 2026-10-01 | Added `@vitest/coverage-v8` to `packages/shared`; `test` enforces 100% coverage on `src/status/**`.           | Phase 3 acceptance requires 100% line/branch coverage on status functions.                          |
| 2026-10-01 | Package name stays `@mrdash/shared` (prompt says `@app/shared`).                                              | Already used by both apps since Phase 1; renaming adds churn for no benefit.                        |
| 2026-10-01 | List filters accept CSV or repeated params via `multiValue`; paginated responses are `{ items, nextCursor }`. | Spec gives multi-select filters and cursor pagination without wire shapes.                          |
| 2026-10-01 | GitLab `locked` state is treated as open; display metadata uses lucide icon names and `status-*` tokens.      | Spec doesn't cover `locked`; keeps shared free of React/lucide and raw colors.                      |
